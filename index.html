Step 1: Environment Setup (WSL2 + pyenv + Poetry)

Dev work happens inside Ubuntu on WSL2 to replicate production Linux and prevent platform parity defects. 

# 1. Base build dependencies in Ubuntu (compiles Python 3.12 without missing modules)
sudo apt update && sudo apt install -y build-essential pkg-config gcc libssl-dev \
  zlib1g-dev libbz2-dev libreadline-dev libsqlite3-dev libffi-dev libpq-dev

# 2. pyenv setup & Python 3.12.3
curl https://pyenv.run | bash
pyenv install 3.12.3
pyenv global 3.12.3

# 3. Poetry project dependencies
poetry add fastapi "uvicorn[standard]" sqlalchemy psycopg2-binary alembic \
  pwdlib argon2-cffi bcrypt==4.0.1 "python-jose[cryptography]" slowapi secure
poetry add --dev pytest pytest-asyncio httpx faker pytest-cov bandit
Step 2: Database Layer (PostgreSQL + SQLAlchemy + Alembic)

Alembic revisions track schema state alongside code in Git, preventing manual migration issues. 

# Initialize & run migrations
poetry run alembic revision --autogenerate -m "create users table"
poetry run alembic upgrade head

# Database Connection String for Supabase Transaction Pooler (Port 6543)

Real Issues Encountered & Resolved (14 Bugfixes)
1. Swagger UI Blank Screen (CSP Fix)

Cause: CSP blocked Swagger CDN script in browser. Fix: Implemented DEBUG check with relaxed script_src for CDN in development, strict CSP in production.

2. WSL2 Supabase Connection Failure (IPv6)

Cause: Direct port 5432 resolved to IPv6 which WSL2 can't route. Fix: Switched to Transaction Pooler on port 6543 (IPv4).

3. Tests Failing with HTTP 429 (Rate Limit)

Cause: Pytest runs quickly and triggered the 5 request/min ceiling. Fix: Exported TESTING=true in test fixtures to generate unique request IDs.

4. secure v2.0.1 Builder API Change

Cause: v2.x replaced keyword args with builder pattern. Fix: Refactored to Secure.with_default_headers() and SecureASGIMiddleware.

5. GitHub Push 408 / HTTP2 Framing

Cause: WSL2 HTTPS buffer congestion. Fix: Switched repository remote to SSH with ed25519 authentication.

6. Docker Build poetry install Failure

Cause: Missing README.md referenced in pyproject.toml and root packaging attempt. Fix: Added README.md to COPY and --no-root flag.
